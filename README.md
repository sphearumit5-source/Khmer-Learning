# Khmer Learning (កម្មវិធីស្វ័យសិក្សាថ្នាក់បឋមសិក្សា) 🇰🇭

**Khmer Learning** គឺជាថ្នាលអប់រំឌីជីថលបែបទំនើប ឆ្លើយតបគ្រប់ឧបករណ៍ (Desktop, Tablet, Mobile) សម្រាប់សិស្សានុសិស្សកម្រិតបឋមសិក្សាកម្ពុជា (ថ្នាក់ទី ១ ដល់ ទី ៦) ស្របតាមកម្មវិធីសិក្សាជាតិរបស់ក្រសួងអប់រំ យុវជន និងកីឡា។

ចំណុចពិសេស៖ **ផ្ទៃមុខកម្មវិធី (User Interface) ទាំងមូលជាភាសាខ្មែរ ១០០%** រួមមាន ការរុករក ប៊ូតុង ចំណងជើង ទម្រង់បែបបទ សារបញ្ជាក់សុពលភាព ខ្លឹមសារមេរៀន សំឡេងអាន ការពន្យល់លំហាត់ ផ្ទាំងគ្រប់គ្រង និងសារដំណឹងផ្សេងៗ ដោយប្រើពុម្ពអក្សរខ្មែរយូនីកូដ (Kantumruy Pro និង Noto Sans Khmer)។

## 🌟 លក្ខណៈពិសេសចម្បងៗ (Key Features)

1. **មុខវិជ្ជាគោលទាំង ៤ សម្រាប់ថ្នាក់ទី ១ ដល់ ទី ៦**៖
   - 📖 **ភាសាខ្មែរ**៖ ព្យញ្ជនៈ ស្រៈនិស្ស័យ ការផ្សំពាក្យ វេយ្យាករណ៍ និងការអានអត្ថបទ
   - 🔢 **គណិតវិទ្យា**៖ លេខ វិធីគណនាបូក ដក គុណ ចែក ប្រភាគ និងធរណីមាត្រ
   - 🌍 **ភាសាអង់គ្លេស**៖ ការស្វាគមន៍ ពាក្យគន្លឹះ ប្រយោគសន្ទនា និងវេយ្យាករណ៍បឋម
   - 🧭 **សិក្សាសង្គម**៖ បរិស្ថាន ដើមឈើ អនាម័យ ភូមិសាស្ត្រ និងវប្បធម៌ខ្មែរ
2. **ឧបករណ៍ជំនួយការរៀនសូត្រ (Learning & Media Viewer)**៖
   - រូបភាពគំនូរជីវចលអប់រំ និងអត្ថបទសំឡេងពន្យល់
   - របារចាក់សំឡេងអានឮៗ (Audio Reader) ជាមួយការបញ្ជាល្បឿនអាន (0.8x, 1x, 1.2x)
3. **កម្រងសំណួរតេស្តអន្តរកម្ម (Interactive Quizzes)**៖
   - សំណួរពហុជ្រើសរើស (Multiple Choice)
   - សំណួរត្រូវ ឬ ខុស (True/False)
   - សំណួរបំពេញចន្លោះ (Fill-in-the-blank)
   - ការគណនាពិន្ទុ និងផ្ទៀងផ្ទាត់លើ Backend ដោយសុវត្ថិភាព (មិនបញ្ចេញចម្លើយមុនពេលប្រឡង)
   - ការពន្យល់លម្អិតជាភាសាខ្មែរ និងចលនាបាញ់កាំជ្រួចអបអរសាទរ (Confetti) ពេលប្រឡងជាប់
4. **ផ្ទាំងវឌ្ឍនភាពសិក្សា (Student Progress Dashboard)**៖
   - តាមដានមេរៀនដែលបានបញ្ចប់ និងអត្រាភាគរយតាមមុខវិជ្ជា
   - ពិន្ទុតេស្តមធ្យម និងផ្កាយកិត្តិយស (Stars)
   - ប្រព័ន្ធមេដាយសម្រេចបាន (Badges): ជំហានដំបូង, ជើងឯកតេស្ត, អ្នកស្រឡាញ់ការអាន, អ្នកពូកែគណិត, មិត្តល្អគ្រូឆ្លាត
   - ប្រវត្តិនៃការធ្វើតេស្តលម្អិត
5. **គ្រូឆ្លាត AI (AI Tutor in Khmer)**៖
   - គ្រូបង្រៀននិម្មិតឆ្លាតវៃ ឆ្លើយតបជាភាសាខ្មែរងាយយល់ សមរម្យសម្រាប់កុមារ និងមានសុវត្ថិភាពខ្ពស់
   - បន្ស៊ាំការពន្យល់ទៅតាមកម្រិតថ្នាក់ (ថ្នាក់ទី ១ ដល់ ទី ៦) និងមុខវិជ្ជា
   - ប៊ូតុងអានចម្លើយរបស់ AI ជាសំឡេង
   - ប្រព័ន្ធ Demo/Fallback ឆ្លាតវៃដែលដំណើរការភ្លាមៗទោះគ្មាន API Key (មិនក្លែងបន្លំចម្លើយឡើយ)
6. **ផ្ទាំងគ្រប់គ្រងលោកគ្រូ-អ្នកគ្រូ (Teacher & Admin Portal)**៖
   - ស្ថិតិទូទៅនៃថ្នាក់រៀន (ចំនួនសិស្ស មេរៀន កម្រងសំណួរ ពិន្ទុមធ្យម)
   - បញ្ជីរាយនាមសិស្ស និងតាមដានលទ្ធផលបុគ្គល
   - ការគ្រប់គ្រងមេរៀន (បន្ថែមមេរៀនថ្មី កែប្រែ និងលុប)
   - ការត្រួតពិនិត្យសំណួរ និងកម្រងតេស្ត

## 🚀 ការដំឡើង និងដំណើរការក្នុង Windows PowerShell

### ១. លក្ខខណ្ឌតម្រូវជាមុន (Prerequisites)

### ២. ការរៀបចំ និងដំណើរការ Backend (FastAPI)

បើកផ្ទាំង Windows PowerShell ទី ១៖
```powershell
# ១. ចូលទៅកាន់ថតគម្រោង
cd "d:\Khmer Learning"

# ២. បង្កើត និងបើកដំណើរការ Virtual Environment (ប្រសិនបើមិនទាន់មាន)
python -m venv venv
.\venv\Scripts\Activate.ps1

# ៣. ដំឡើងកញ្ចប់បណ្ណាល័យ Python
pip install -r backend\requirements.txt

# ៤. រៀបចំឯកសារ .env
copy backend\.env.example backend\.env

# ៥. ដំណើរការ Backend Server
$env:PYTHONPATH="backend"
$env:PYTHONIOENCODING="utf-8"
.\venv\Scripts\uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

Backend នឹងដំណើរការនៅ៖ `http://127.0.0.1:8000`  
ឯកសារ API Documentation (Swagger UI) អាចមើលបាននៅ៖ `http://127.0.0.1:8000/docs`

> **ចំណាំសំខាន់**៖ មូលទិន្នន័យ SQLite នឹងត្រូវបង្កើតដោយស្វ័យប្រវត្តិជាមួយទិន្នន័យគំរូទាំងអស់ភ្លាមៗ មិនបាច់ដំឡើងអ្វីបន្ថែមឡើយ! ប្រសិនបើចង់ប្តូរទៅ PostgreSQL សូមពិនិត្យឯកសារ [database/README_DB.md](file:///d:/Khmer%20Learning/database/README_DB.md)។
